# Support

## Something looks wrong

Open a bug report with:

- Pi TimeLens, Pi, and Node.js versions;
- terminal width and operating system;
- expected and actual timing output;
- the smallest safe reproduction;
- whether the issue survives `/reload` in a fresh Pi session.

Never attach credentials, complete session files, private prompts, tool arguments, or tool output. Reduce evidence to the relevant timing records.

## Questions and ideas

Use the question or feature-request templates. For metric questions, read [Metric definitions](docs/metrics.md) first.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
